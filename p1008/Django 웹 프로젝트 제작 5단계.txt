Django 웹 프로젝트 제작 5단계 개괄
1단계: 프로젝트 및 앱 생성 (완료)
django-admin startproject spro05
<만약 안되면,python -m django startproject project01>
python manage.py startapp students
python manage.py startapp home
python manage.py startapp stuscore
으로 뼈대(프로젝트와 앱 폴더들)를 만들고 서버 구동을 확인한 단계입니다.

2단계: 데이터 모델 설계 및 DB 반영 (models.py, migrate)

웹사이트에서 다룰 데이터(학생 정보, 성적 등)의 칸을 정하고 데이터베이스에 표를 생성하는 단계입니다.

3단계: 관리자(Admin) 등록 및 테스트 (admin.py)

만든 데이터를 관리자 페이지에서 직접 넣고 수정하며 잘 저장되는지 검증하는 단계입니다.

4단계: URL 및 뷰(View) 연결 (urls.py, views.py)

사용자가 웹 주소로 접속했을 때, 데이터베이스에서 정보를 꺼내 화면으로 보내주는 연결 통로를 만드는 단계입니다.

5단계: HTML 템플릿(화면) 구현 및 출력 (templates/)

가져온 데이터를 사용자 눈에 예쁘게 보이도록 웹 페이지(HTML)로 그려주는 최종 단계입니다.

3) model.py 작성 : 입력양식, 자료저장소 만들기(틀만 만들기)
students의 models.py의 내용
---------------------------------------------------------------------------------
from django.db import models

class Stu(models.Model):
    name = models.CharField(max_length=100)
    major = models.CharField(max_length=100)
    age = models.CharField(default=0)
    grade = models.CharField(default=0)
    gender = models.CharField(max_length=30)

def __str__(self):
    return f"{self.name},{self.major},{self.age},{self.grade},{self.gender}"
---------------------------------------------------------------------------------


3. views.py 파일 - 저장하고, 보여주고, 화면전환하는 기능

from django.shortcuts import render, redirect # 출력하는 함수, 다른페이지로 강제이동시키는 함수(redirect)함수를 가져와라
from students.models import Stu # Stu모델을 가져와라

# GET방식 : 주소창에 주소를 치거나 링크를 눌러서 페이지를 열라고 요청 시 실행
def swrite(request):
    if request.method == 'GET':
        print("GET 페이지가 로딩되었습니다.")
        return render(request,'swrite.html') # 입력양식인 swrite를 실행하라
    elif request.method == "POST": # 입력양식을 채우고 저장버튼을 눌러 데이터가 서버로 전송되면 실행
        print("POST 페이지가 로딩되었습니다.")
        name = request.POST.get('name') # 사용자가 입력 폼에 입력한 이름 데이터를 서버로 가져와서 name에 넣어라. 즉, 사용자가 models.py를 통해서 입력한 것을 담을 틀을 준비해 뒀다가 입력되면 거기에 집어 넣어라
        major = request.POST.get('major')
        age = request.POST.get('age')
        grade = request.POST.get('grade')
        gender = request.POST.get('gender')

        qs = Stu(name=name,major=major,age=age,grade=grade,gender=gender) # model.py에 있는 클래스인 Stu 변수는 views.py 변수에 할당하라.
        qs.save()

        print(name,major,age,grade,gender)
        return redirect('/') # 메인페이지로 이동하라
	# return redirect('/students/swrite/') # 입력페이지로 이동(입력사항만 없어짐)

def slist(request):
    return render(request,'slist.html')
